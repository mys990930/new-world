# v2

## Role

- hold the region-first world-generation scaffold after legacy V1 removal
- assemble the atlas raw-field, skeleton, and region-classification inputs that later V2 steps will consume

## Responsibilities

- define the first public V2 scaffold types
- prepare padded atlas fields and structure inputs for a chunk
- resolve the matching region classification window
- reserve a continuous realization-field stage between classification and prototype so prototype does not read atlas-cell semantic labels as its primary control surface
- expose a stable center-sample region classification so later V2 steps can build base heightfield and meso solves on top
- carry the corridor window into the scaffold boundary and hand it to prototype as an explicit pre-meso constraint
- reserve ownership for realization field, corridor, prototype, meso-apply, smoothing, hydrology, and voxelization stages even before full implementation exists
- treat `prototype.md` as the authoritative design contract for the base-heightfield solve stage

## Non-Responsibilities

- final chunk block placement
- final river carve
- meso solve
- material solve

## Public Interface

```rust
prepare_chunk_v2_inputs(coord: ChunkCoord, meta: &WorldMeta) -> ChunkGenerationV2Inputs
build_chunk_v2_scaffold(coord: ChunkCoord, meta: &WorldMeta) -> ChunkGenerationV2Scaffold
build_chunk_corridor_window(chunk: ChunkCoord, inputs: &ChunkGenerationV2Inputs) -> ChunkCorridorWindow
build_chunk_base_heightfield_prototype(
    chunk: ChunkCoord,
    inputs: &ChunkGenerationV2Inputs,
    corridor_window: &ChunkCorridorWindow,
) -> BaseHeightfieldPrototype
build_chunk_meso_applied_prototype(
    chunk: ChunkCoord,
    inputs: &ChunkGenerationV2Inputs,
    corridor_window: &ChunkCorridorWindow,
    prototype: &BaseHeightfieldPrototype,
) -> MesoAppliedPrototype
```

## Current Status

- implemented as a staged scaffold with initial corridor, prototype, and Wave 1 meso realization builders
- scaffold assembly now carries atlas raw fields, skeleton, region classification, meso guides, and corridor-window handoff into the prototype and meso boundaries
- the next architectural insertion point is a generation-side realization-field solve that will sit between discrete region classification and the prototype broad-shape solve
- river corridor solve now exists as a standalone deterministic builder over prepared V2 inputs
- biome-aware base heightfield solve now exists as an initial broad-shape builder over prepared inputs plus corridor constraints
- a first chunk-local meso deformation pass now exists on top of the prototype using the atlas-owned Wave 1 guide channels
- the old V1 runtime generator has been removed rather than kept alive beside this scaffold
- public generation entrypoints now intentionally fail until real V2 realization lands
- later V2 work should add a continuous realization-field solve, final hydrology, and voxelization
- scaffold assembly now carries corridor solve into `ChunkGenerationV2Scaffold`
- prototype now emits a full-grid broad-shape scaffold, while meso spends part of that relief budget before later detail and final realization remain deferred
