# profile

## Role

- retain the small diagnostic terrain-profile vocabulary still referenced by preview and probe-facing types

## Current Scope

- `TerrainProfile` is no longer an active realization engine
- it survives only as a lightweight label set:
  - `DeepOcean`
  - `Shelf`
  - `Coast`
  - `Plain`
  - `Upland`
  - `Ridge`

## Notes

- the removed V1 surface solver used these values as shape-family categories
- V2 may eventually keep, replace, or reinterpret them, but they are not currently the biome system and they no longer drive block placement
